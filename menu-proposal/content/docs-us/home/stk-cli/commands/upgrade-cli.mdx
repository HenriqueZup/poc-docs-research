> In this section, you will find how upgrade STK CLI.

<br/>

If you already use 4.5.x STK CLI version, you have to upgrade to the new version. See below:

**Step 1.** In your terminal, execute the command:

```bash
stk upgrade --force 
```

**Step 2.** To confirm, execute:

```bash
stk --version
```

STK CLI output is:

```bash
StackSpot version: 1.0
stk cli version: 5.0.5
```
