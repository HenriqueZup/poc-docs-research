## **Requirements**

- [**You must have Account Holder or Workspace Admin permission to proceed**](home/account/organization/access-management/roles.md ).

## **Workspace Set up**

Follow the steps to set up your Workspace on the [**StackSpot Platform**](https://app.stackspot.com/login):

### **Step 1. Create your Workspace**

You have to create your Workspace to organize your Applications and Infrastructure. To do so, [**follow the steps on the 'Create Workspace' page**](home/workspace/create-workspace.md).

### **Step 2. Add Stacks and configure the context**

Now, add Stacks to your Workspace. After that, configure the **Context**.
These are prior configurations of input values for plugins and other resources in a Stack, to **standardize** or **streamline** the creation of Shared Applications and Infrastructures in StackSpot.

- [**Follow the steps on the guide**](home/workspace/stacks-and-context/setup-context.md)

### **Step 3. Insert links**

StackSpot provides resources for generating links to your content. You can create these links using Plugins within your Workspace. See more details on the [**Add Links to your Workspace**](home/workspace/links-on-workspace.md).

### **Step 4. Cloud Account set up**

> This configuration is done by someone with access to an AWS account.

<br/>

You must configure a cloud account in StackSpot to deploy your Applications. This configuration is done via Runtime Self-Hosted. To set it up, check the [**Runtime Self-Hosted configuration guide**](deployment/deploy/use-self-hosted/index.md).

:::caution

If your Account meets the following conditions: 

1. **Enterprise Accounts created before 2024**.

Deployment can still be done via the StackSpot EDP Deployment Engine. You then need to configure your Cloud Account within your Workspace. To see how to configure each provider, go to:

- [**Configure AWS Cloud Account**](home/workspace/config-cloud-account.md);
- [**Configure Cloud Azure Account**](home/workspace/config-cloud-account-azure.md);

For information on this deployment model, [**see StackSpot Deploy Engine**](deployment/runtime-engine/intro-runtime-engine.md). Validates that the variable of type list contains all the values contained in **`value`** and no other elements.

:::
