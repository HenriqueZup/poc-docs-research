Integrating your <Tooltip text="Source code management (SCM) tracks changes to a code repository, keeping a record of alterations and assisting in managing conflicts that arise when integrating updates from different contributors.">SCM</Tooltip> (Source Code Management) with StackSpot brings some utilities to teams and can be run remotely via the CI/CD pipeline. Currently, StackSpot has 4 possible flows to be executed:

1. Create Application;
2. Create Infrastructure;
3. Apply Plugins;
4. Execute Actions.  

<br/>

StackSpot supports the following SCMs:  

- GitHub;
- Azure DevOps;
- BitBucket;
- GitLab.
