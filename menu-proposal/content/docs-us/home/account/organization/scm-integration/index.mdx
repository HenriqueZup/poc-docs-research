---
title: Integrate Account SCM with Workflow
---

Integrating your <Tooltip text="Source code management (SCM) tracks changes in a code repository, keeps a record of modifications, and helps manage conflicts that arise when merging updates from different contributors.">SCM</Tooltip> (Source Code Management) with StackSpot provides useful tools for teams, which you can run remotely through CI/CD pipelines.

Currently, StackSpot offers five workflows you can run:

1. Application Creation
2. Infrastructure Creation
3. Plugin Application
4. Action Execution
5. StackSpot Workflow Execution

The StackSpot Workflow SCM configuration supports the following SCMs:

- GitHub
- Azure DevOps
- BitBucket
- GitLab
