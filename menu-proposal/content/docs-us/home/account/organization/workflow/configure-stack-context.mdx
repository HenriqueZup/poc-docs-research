## Introduction


When you set up a Context for your Workflow, you're basically **setting values for the input Actions in that Workflow**. These values **will be the same** for all Workflow users, whether mandatory or just suggested.

You can set Workflow contexts at three levels:

1. Account;
2. Stack in the Account;
3. Stack in the Workspace.

<br/>

If you **make an input mandatory for an Action** in your Workflow, **all Stacks and Workspaces** using this Workflow **must follow that rule**. However, users can still change inputs that are not marked as mandatory.

If someone sets a Workflow input as mandatory in a specific Stack, the Workspace using it can't change it. And if the Workspace Administrator sets another input as mandatory, everyone in the Workspace must use all mandatory inputs from the Account, Stack, and Workspace without changing them.


See below the steps to configure a Workflow Context in a Stack: 

**Step 1.** Go directly to the [**Account Portal**](http://myaccount.stackspot.com); or after [**logging into the StackSpot Portal**](https://app.stackspot.com/), click on your **profile avatar**.

**Step 2.** Select the **'Organization'** option from the displayed menu;

**Step 3.** In the Account Portal main menu, select the StackSpot EDP product and click on **'Workflow'**;  

**Step 4.** Within the **'Stacks'** section, click the **'Workflow details'** button on the **right side** of the Stack you want to set up the Workflow Context;

**Step 5.** Within the Workflow page, click the down arrow next to the Action you want to set up input values. You have two options:

1. **Suggest a value:** Simply type the desired value into the field.
2. **Make a value mandatory:** Enter the value and then check the **'Mandatory'** checkbox. This ensures that a Workspace utilizing this Stack cannot alter this value.

Repeat this process for all Inputs you wish to configure (except those already designated as Mandatory at the Account level). 

**Step 6.** Click **'Save'** at the bottom of the page and confirm it. 

You've configured a Workflow Context in a Stack.
