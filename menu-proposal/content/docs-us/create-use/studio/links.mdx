> In this section, you will find information about links available on StackSpot.

<br/>


StackSpot provides resources for creating links to your content. You can generate these links using Plugins within your Workspace and integrate them into your Applications and Infrastructures.

You can also connect external tools to a Workspace via Links, accessible in all shared Applications and Infrastructures.

## **Embedded links**

You can enhance your Workspace with external links, which are panels that provide easy access to tools such as Grafana, Prometheus, Splunk, and more. This integration improves the functionality and convenience of your Workspace.

As a content creator, you can:

- Add external links to your Workspace.
- Add and delete external links in Applications created within your Workspace.

To learn how to add Static and Embedded Links, refer to the [**Manage Links in Your Application guide**](create-use/use-content/application/manage-links-in-app.md).

## **Dynamic links**  

You can add Dynamic Links that adjust to the application's current parameters. Through the **'connections'** output, you can reference URLs that will be created later.

:::info
Dynamic Links work with Infra and App Plugins.
:::

You can only disable the Links visualization in the Workspace if:

- You have a `workspace:manage` role.
- You are the Application owner.

:::warning  
It is not possible to remove a Dynamic Link. You can only hide it from users with permission to edit Links. Afterward, you can unhide a Dynamic Link for the same user profiles.  
:::
