> In this section, you will find information about Studios.

<br/>

Studios are essential for creating and distributing Stacks and their associated Plugins. They provide a branded environment for users with Creator permissions, helping them manage and organize their work. Studios also allow you to connect to Teams and control how they access and interact with content.

## **Key concepts in Studios**

- [**Slugs:**](create-use/studio/slugs.md) Unique identifiers (often part of URLs) for Accounts, Studios, Stacks, and Plugins. They help create distinct StackSpot URLs.

- [**Plugin:**](create-use/create-content/plugin/create-plugin.md) A Plugin adds new features to an application and is always linked to a Studio.

- [**Action:**](create-use/create-content/action/actions.md) Automates tasks on your computer.

- [**Stacks:**](create-use/create-content/stack/create-stack.md) Groups of Plugins that provide developers with the resources they need to build applications.

- [**YAML files:**](create-use/create-content/yaml-files/intro-yaml.md) YAML is a data serialization language used for inputs. It supports features like Inputs, Advanced Inputs, Declarative Hooks, Metadata, and Jinja. For more details, refer to the StackSpot documentation.

## **What you can do in Studios**

- Create and publish Plugins.
- Publish and validate Actions and link them to Infrastructure Plugins.
- Add Plugins, Starters, and Links to a Stack.
- Check the version of a Stack and publish updates.
- Create and customize Slugs.
- Configure [**Connection Interface suggestions**](create-use/connections/connection-interface-suggestion.md).
- Set up YAML files.
- Access Content Insights to track the progress and performance of your creations, publications, and applications.
- View general Studio information or delete a Studio if needed.
