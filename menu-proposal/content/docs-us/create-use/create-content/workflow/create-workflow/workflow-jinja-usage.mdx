### **Using JINJA Expressions**

Using Jinja in StackSpot extends to Workflows. You can use expressions as variables for **`inputs`**, **`outputs`**, and **`computed-inputs`** of Actions, Plugins, and Workflows. [**For more information, see the page about using Jinja in StackSpot**](create-use/create-content/yaml-files/jinja.md).
