> In this section, you will find details about Stacks.

<br/>

A Stack is a comprehensive collection of technologies necessary for an Application to function. It encompasses the application code and the infrastructure required to provide resources to the Application, whether hosted in the cloud or on a local server.

The primary aim of a Stack is to streamline the development process for developers, allowing them to concentrate solely on building the Application itself. It minimizes the need for extensive configuration of frameworks or infrastructure, simplifying the development workflow.

A Stack allows you to:  

- Add Plugins;
- Create Starters.

:::info  

Stacks are visible within every Account in StackSpot. Any user with access to StackSpot has the capability to create and version Stacks.

:::
