### **What are the .yaml files?**

These are the files that contain all the configurations of the structures generated by the developer when creating:

- **Plugins**
- **Actions**
- **Starters**
- **Specification files**
- **Applications**
- **Infrastructures**

For some of these configuration files, there are resources so that you can edit behaviors and information to create content for StackSpot.

In this section you will find details about YAML files, Inputs, Metadata, Declarative Hooks and Jinja in StackSpot. Check out the details:
