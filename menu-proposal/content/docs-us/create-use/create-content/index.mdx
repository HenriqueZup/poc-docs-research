### What is Content in the StackSpot?

Content is any piece created using the StackSpot Engine framework. This includes [**Stacks**](create-use/create-content/stack/stacks.md), [**Starters**](create-use/create-content/stack/create-starter.md), [**Plugins**](create-use/create-content/plugin/plugins.md), [**Actions**](create-use/create-content/action/actions.md), and Links, which can be reused for various purposes.
Developers create content in the [**Studios**](create-use/studio/intro-studio.md), which are dedicated spaces for content creation.

### **Where can I use StackSpot's content?**

Workspaces are where you can use the content created in a Studio. A Workspace allows you to develop Applications and Infrastructure, depending on your needs and preferences. You can also set up a Cloud Provider if you need to.

To learn more about Workspaces and how to create an Application or Infrastructure, refer to the links below:

- [**How to Create an Application**](create-use/use-content/application/index.md).
- [**How to create an Infrastructure**](create-use/use-content/infra/infrastructure.md).
- [**Learn more about the Workspaces section**](home/workspace/about-workspace.md).
