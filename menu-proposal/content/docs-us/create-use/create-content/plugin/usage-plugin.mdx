> In this section, you will find a guide on how to visualize the use of a Plugin in a Stack, Starter, Application and/or Infrastructure.

<br/>

StackSpot allows you to see how a Plugin is used and linked to other content, Applications, and Infrastructures, for example. 

To view this data, follow the steps below:

**Step 1**: Access your **Studio**;  
**Step 2.** Click on the **Plugin** you want to view and then on the **'Usage Insights'** section;  

You can now view the content linked to a Plugin.

Within this section, you can view the following subsections:

#### **Stacks**  

You can see which Stacks a Plugin version is linked to. To check the usage details, click on the Stack you want to view.

Inside, you'll find information such as:

- **Stack version**: Which Stack versions use a Plugin version.

- **Plugin version**: Which versions of the Plugin are being used in a version of the Stack.

:::tip 

[See the rules for versioning, deprecating, and unpublished a Plugin in a Stack](create-use/create-content/plugin/plugin-version.md).

:::

To **deprecate** the selected version, click on the icon next to the version and then on the **'Deprecate version'** button. Now follow the steps below:

**Step 1.** Select the reason: choose between **Lack of maintenance**, **Security problems**, **Bugs** or **Other**; 

**Step 2.** Type the word **DEPRECATE** in the text field to confirm the depreciation; 

**Step 3.** Click on the button **'Deprecate Plugin Version'**.


You have deprecated the version of a Plugin in a Stack.

#### **Plugins** 

In this subsection you can see which other Plugins are requesting the Plugin in question. To check the usage details, click on the **Plugin** you want to view.

In this subsection, you can see which other Plugins request the Plugin. To check the usage details, click on the **Plugin** you want to view.

Inside, you will find the following information:

- **Plugin version**: Which versions of the Plugin are being requested by other Plugins.

- **Plugin type**: It can be the App or Infra type.

- **Studio**: Which Studio has the Plugin published in?

- **Linked versions**: Which or how many versions is the Plugin linked to? 

To **deprecate** the selected version, click on the icon next to the version and then on the button **'Deprecate Version'**. Now follow the steps below:

**Step 1.** Select the reason: choose between **Lack of maintenance**, **Security problems**, **Bugs** or **Other**; 

**Step 2.** Type the word **DEPRECATE** in the text field to confirm the depreciation; 

**Step 3.** Click on the button **'Deprecate Plugin Version'**.

You have deprecated the version of a Plugin with the requirement of the Plugin you are viewing. 

#### **Workflows (Beta Version)**

In this subsection, you can see which other [**Workflows (Beta Version)**](beta-version\workflow-beta\index.md) request the use of the selected Plugin. To view usage details, click the Workflow you want to inspect.  

Inside the Workflow, you'll find the following information:  

- **Plugin Version**: Which plugin versions are required by other Workflows?  

- **Linked Versions**: Which and how many versions is the Workflow linked to?  

To **deprecate the selected version**, click the icon next to the version, then click **'Deprecate version'**. Follow these steps:  

**Step 1.** Select the reason: choose from **Lack of maintenance**, **Security issues**, **Bugs**, or **Other**;  

**Step 2.** Type **DEPRECATE** in the text field to confirm deprecation;  

**Step 3.** Click the **'Deprecate Workflow version'** button.  

#### **Starters**  

Within a Stack, you can see which versions of a Plugin the Starter is linked to. To check the usage details, click on the **Starter** you want to view.

Inside, you'll find information such as

- **Starter name**
- **Type**: App (Application) or Infra (Infrastructure).
- **Stack version**: Which versions of the Stack is this Starter being used? 
- **Studio Version**: Which versions of this Starter are in a Studio?

#### **Infrastructures**

You can see which infrastructures the Plugin is using. To check the usage details by Plugin version, click on the **Infrastructure** you want to view.
Inside, you will find information such as:

- **Plugin version**: Which versions of the Plugin are being used in the Infrastructure?

- **Workspace**: Which Workspaces is the Plugin being used in?

- **Linked versions**: Which versions is this Plugin linked to? 

To **deprecate** the selected version, click on the icon next to the version and then on the button **'Deprecate version'**. Now follow the steps below:

**Step 1.** Select the reason: choose between **Lack of maintenance**, **Security problems**, **Bugs** or **Other**; 

**Step 2.** Type the word **DEPRECATE** in the text field to confirm the depreciation; 

**Step 3.** Click on the button **'Deprecate Plugin Version'**.

You have deprecated the version of a Plugin in an Infrastructure.

#### **Applications**  

You can also see which Applications the Plugin is being used for. To check the usage details by Plugin version, click on the **Application** you want to view.

- **Plugin version**: Which versions of the Plugin are being used in the Application?
- **Workspace**: Which Workspaces is the Plugin being used in?
- **Linked versions**: Which versions is this Plugin linked to? 

#### **Not in use**   

In this section, you can see which versions of the Plugin are **not** being used anywhere in StackSpot.

It is also possible to deprecate the version of a Plugin that is not being used. To do this, follow the steps below:

**Step 1.** In the row of the Plugin version you want to deprecate, click on the icon in the **'Manage version'** column;

**Step 2.** Click the **'Deprecate version'** button.
