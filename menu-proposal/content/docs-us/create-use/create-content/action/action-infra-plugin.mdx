> In this section, you will find a guide on adding an Action to an Infra Plugin.

After [**publishing**](create-use/create-content/plugin/publish-action.md) and [**validating**](home/stk-cli/commands/action-commands.md) an Action in a **Studio**, you can easily [**add it to an Infra Plugin**](create-use/create-content/plugin/plugins.md).

:::warning

Before proceeding, check if your Action **requires at least one Connection Interface generated by the Infra Plugin**.
If you don't have this Action, see the [**How to create an Action**](create-use/create-content/action/run-action.md#use-connections-interfaces) guide.

:::

## **Requirements**

- [**You must be logged in to the StackSpot Platform**](https://app.stackspot.com/login);
- Be in a [**Studio**](create-use/studio/intro-studio.md);
- You must have a [**Stack**](create-use/create-content/stack/stacks.md) with Infra Plugins.
- You must have [**a Stack with Actions**](create-use/create-content/action/add-action-stack.md).

## **Steps**

Follow these steps:

**Step 1.** [**Log in**](https://app.stackspot.com/login) to the StackSpot Platform;

**Step 2.** Access your **'Studio'**;

**Step 3.** On the main menu, click the **'Stacks'** button;

**Step 4.** Access the Stack and click the **Stack version** you want to add the Action;

:::warning

You can only add an Action to an Infra Plugin if your Stack is in **draft**.

If the Stack is already published, you must [**create a new version**](create-use/create-content/stack/stack-version.md).

:::

**Step 5.** In the Stack's main menu, click **'Plugins'**. Then, select the **'Infra'** section;

**Step 6.** Choose the Plugin to add the Action to. Then click **'Select Action'**;

**Step 7.** On the right side of the screen, select the Actions to add to the Infra Plugin. Then click the **'Add'** button.

:::warning  
You cannot choose a specific Action version when associating an Action with the Infra Plugin that uses the [**range template**](create-use/create-content/plugin/plugin-version.md).
:::

You've added an Action to an Infra Plugin. Whenever the Infra Plugin generates Connection Interfaces, it will have the same configuration.
