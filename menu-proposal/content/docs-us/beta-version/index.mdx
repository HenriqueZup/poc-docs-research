## **StackSpot Beta version**

The beta version has features yet to be available to all customers. It's aimed only at StackSpot **early adopters**, which means customers who started using StackSpot from its beginning.

If you do not fit this profile, you can check out the **Release Notes to stay up-to-date** with the latest releases and see when the beta features will be available for everyone. 

## **Limitations**

- The beta version does not work on production;
- If you are an early customer, you can test these new feature.

## **Recent beta releases**

The first version of StackSpot's Workflow has been released.

In StackSpot, a Workflow is an automated and configurable process that executes one or more jobs. The jobs in a Workflow execute steps, such as running StackSpot Actions, applying Plugins, and executing other Workflow to perform various tasks while creating your Application or Infrastructure.

Workflows are defined in YAML files and available on the StackSpot Portal after publication in the Studios. A Studio can have several Workflows, each for specific or more general use.

- [**For more details, access more information about Workflow**](beta-version/workflow-beta/about-workflow.md).

- [**Get started with Workflow**](beta-version/workflow-beta/getting-started-workflow.md).
