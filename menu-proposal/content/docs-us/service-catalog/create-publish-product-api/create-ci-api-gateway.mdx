> In this section, you will learn how to create and publish an API.

<br/>


Before **linking** an API Gateway [**Connection Interface**](create-use/connections/connection-interface.md) to your API, you need to **create it in the Workspace**. 

Follow the steps below:  

**Step 1.** Access your Workspace on the [**StackSpot Platform**](https://stackspot.com/en/);  

**Step 2.** Click on the **'Connection Interfaces'** subsection in the menu on the left-hand side of the screen;  

**Step 3.** Now click on the tab **'Created by users'**;  

**Step 4.** Click on the **'Create Connection Interface'** button;  

**Step 5.** In **'Create Connection Interface'**, enter the following data:  

- **Name**: fill in what you want to name the Connection Interface.  
- **Connection Type**: select the **`aws-api-gateway-rest-con`** option. 

Then click on the **'Next'** button.

In the **'Parameters'** screen, enter the **arn** and **name** of your Connection Interface. 

> If you chose the **'Define values per environment'** option, select the environments and include an **arn** and a **name** for each. 

<br/>

To continue, click on the **'Next'** button;

**Step 7.** Review the **Summary** and **Parameters**. Click **Finish**.
Your Connection Interface has been created.

## **Next step** 
You can now [**create and publish an API**](service-catalog/create-publish-product-api/api-catalog.md).
