> In this section, you will find more details about the products on the Service Catalog.

<br/>

The Product is a set of APIs. It is an entity exposed in the Service Catalog representing that set of associated APIs.

![Image showing the Product mentioned above](/img/product.png)

:::tip  

You can already use in the Product the API references.

:::

When you create a Product in the Catalog, it has three statuses:

1. **Draft**: In this status, the Product only appears in the Service Catalog of the Product Owner. Any member of the Account Workspace team can publish it. It is not displayed in the Catalog for the whole organization.

2. **Published**: The Product is displayed in the Catalog for the whole organization.

3. **Unpublished**: In this status, the Product stops being displayed in the Catalog, but it can be published again.
