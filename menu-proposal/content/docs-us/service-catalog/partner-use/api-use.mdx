> In this section, you will find how to use an API.

<br/>

After an owner releases your access to an API, you can use one in the StackSpot Catalog.

To do so, follow the steps below:

**Step 1.** Access the Service Catalog. Go the [**StackSpot Platform**](https://app.stackspot.com/login);

**Step 2.** Choose the API you have access to;

**Step 3.** Click on the **'API credentials'** subsection. You will see the following information:

- **API Reference**.
- **Inputs Parameters**.  
- **Responses**.
