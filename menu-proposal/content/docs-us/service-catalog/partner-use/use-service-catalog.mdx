> In this section, you will find how to use the Service Catalog.

<br/>

## **Request Access**

To use the Service Catalog as a partner, you must request access to an **API** or a **Product**. Follow the steps below:

**Step 1.** Access your Service Catalog on the [**Partner Portal**](https://partners.stackspot.com);  

**Step 2.** To request access to an API, follow the instructions:

  1. In the **APIs** subsection, click on the **API** you want to access it;
  2. Within the API section, click **'Request access'** button;  
  3. Select the API you want;
  4. Then click **'Request access'** again.

<br/>  

You requested access to an API. Now, you need the catalog's owner's authorization to use it.

**Step 3.** To request access to a **Product**, follow the instructions below:

  1. In the **Products** subsection, click on the Product you want to access it;
  2. Within the Product section, click **'Request access'** button;  
  3. Choose the Product application you want;
  4. Then click **'Request access'** again.

<br/>

You requested access to a Product. Now, you need the catalog's owner's authorization to use it.
