> In this section, you will find how to set up StackSpot's Deploy.

<br/>

:::caution

The Deploy configuration flow and addition of Cloud accounts in StackSpot in this way is only available for:

- **Enterprise accounts created before 2024**.

**Enterprise accounts created from January 2024 onwards** must deploy via [**Self-hosted Runtimes**](deployment/deploy/self-hosted-runtime.md).
:::

### Before you begin

This guide shows how to set up before working with the StackSpot's Deploy Engine. You will learn more about how to:

- Select a Cloud Provider;
- [**Connect AWS accounts**](home/workspace/config-cloud-account.md);
- [**Create Infrastructure**](create-use/use-content/infra/infrastructure.md);   
- [**Application Infrastructure Deployment**](deployment/runtime-engine/app-deployment.md);  
- [**Infrastructure Deployment**](deployment/runtime-engine/deploy-infra.md).

:::warning
The deployment performed by StackSpot's Runtimes Engine is **not** for the Application itself but for the **Application's Infrastructure**. The **Application** deployment is done via a **Pipeline**.

To learn about this process, navigate to the [**Register Application Deployment Section**](deployment/deploy/register-app-deployment.md). 
:::
