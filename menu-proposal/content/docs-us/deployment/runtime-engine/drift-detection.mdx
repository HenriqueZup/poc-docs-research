## Drift Detection & Auto Reconciliation

 **Drift Detection** identifies when a provisioned Cloud resource or imported from a Deploy Engine is in a different state declared in the code.
 After the drift is detected, the **Auto Reconciliation** reconciles the different resources to the original state. It's automatic.

### Example

Your application's database needs to use the RDS with MySQL X version. But another person changes the RDS version to Y via the AWS console. The Drift detects this change and reconciles the altered value to the original one.  

> Drift Detection is automatic.

:::warning
When you deploy your Application for the first time, Auto-Reconciliation is not enabled.
:::
