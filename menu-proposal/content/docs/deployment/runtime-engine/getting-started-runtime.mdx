> Nesta seção, você encontra o início da sua jornada usando o Deploy da StackSpot.

<br/>

:::caution Cuidado! 
O fluxo de configuração de Deploy e adição de contas Cloud na StackSpot desta forma só está disponível para:

- **Contas Enterprise criadas antes de 2024**.

**Contas Enterprise criadas a partir de Janeiro de 2024** devem fazer Deploy via [**Runtimes Self-hosted**](deployment/deploy/self-hosted-runtime.mdx). 
:::

### **Antes de começar**

Este guia de início engloba a conexão das contas de Cloud, passando pelo provisionamento da Infraestrutura (Infra) e finalizando na operação da Infra que fica disponível para a pessoa desenvolvedora executar as aplicações.

Com a configuração inicial no Deploy, você consegue:

- Selecionar o Provedor da Nuvem que planeja usar;
- [**Conectar contas AWS**](home/workspace/config-cloud-account.mdx);
- [**Criar uma Infraestrutura**](create-use/use-content/infra/infrastructure.mdx); 
- [**Fazer Deploy da Infraestrutura de uma Aplicação**](deployment/runtime-engine/app-deployment.mdx);  
- [**Fazer Deploy de uma Infraestrutura**](deployment/runtime-engine/deploy-infra.mdx).

:::warning Atenção!  
O deploy feito pelo Runtimes Engine da StackSpot **não** é da Aplicação e sim da **Infraestrutura da Aplicação**. O deploy da **Aplicação** é feito via **Pipeline**. 

Para conferir esse processo, navegue até a [**Seção de Registrar Deploy de uma Aplicação**](deployment/deploy/register-app-deployment.mdx). 
:::

### **Pré-Requisitos**

- [**Já ter um Workspace**](home/workspace/create-workspace.mdx);
- [**Ter configurado uma conta AWS Cloud**](home/workspace/config-cloud-account.mdx) ou [**Configurado uma conta Azure Cloud**](home/workspace/config-cloud-account-azure.mdx);
- [**Ter os dados (ou acesso) a conta da Nuvem a ser configurada**](home/account/organization/access-management/roles.md );
- [**Ter criado Ambientes na conta**](home/account/organization/create-env.mdx).

Antes de fazer um dos deploys disponíveis na StackSpot, confira as configurações específicas para sua Conta: 

### **Conta Enterprise**

- [**Configuração Inicial**](home/account/organization/initial-setup.mdx);
- [**Configurar SSO**](home/account/organization/sso-group-mapping/sso-configuration.mdx);
- [**Gerar e revogar Credenciais de Serviço**](home/account/organization/service-credential.mdx).
