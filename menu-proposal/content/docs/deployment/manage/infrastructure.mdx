> Nesta seção, você encontra como a seção de Infraestrutura funciona.

<br/>

No [**Portal da StackSpot EDP**](https://app.stackspot.com/login), você pode acompanhar os status dos Plugins de Infraestrutura depois do deploy. 

Nesta tela, você encontra detalhes como:

- Listagem de Plugins
- Status de cada Plugin

Para saber como acessar a seção de **'Infraestrutura'**, siga o passos.

**Passo 1.** Acesse a [**o Portal da StackSpot EDP**](https://app.stackspot.com/login);

**Passo 2.** Vá até o seu Workspace;

**Passo 3.** Clique na subseção **'Infraestrutura'**;

Pronto, você pode acompanhar o status dos deploys dos seus Plugins.

Um Plugin terá dois status: **Sucesso** e **Erro**.

Quando houver **erro**, você poderá ver o log dele para entender e corrigi-lo. Para isso, clique no botão **'Ir para atividade do log'** para ser direcionado para a seção de [**Atividades**](deployment/manage/activities.mdx).
