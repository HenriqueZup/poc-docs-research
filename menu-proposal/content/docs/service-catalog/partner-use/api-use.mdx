> Nesta seção, você encontra detalhes como usar uma API.

<br/> 

Depois de um **owner** liberar seu acesso à uma API, você pode **usar uma API** no Catálogo de Serviços da StackSpot.

Para utilizar uma API, siga os passos:

**Passo 1.** Acesse novamente o seu Catálogo de Serviços [**no Portal da StackSpot EDP**](https://app.stackspot.com/login);

**Passo 2.** Selecione a API que já está com o acesso liberado;

**Passo 3.** Clique na subseção **'Credenciais da API'**. Você pode ver informações como:

- **Referência da API**.
- **Parâmetros de entrada**.  
- **Respostas**.
