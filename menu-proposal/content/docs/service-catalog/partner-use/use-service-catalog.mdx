> Nesta seção, você encontra como utilizar o Catálogo de Serviços no portal da StackSpot.

<br/>

## **Solicitar Acesso**

Para utilizar o Catálogo de Serviços como Parceiro, você precisa solicitar acesso a uma **API** ou **Produto**. Siga os passos:

**Passo 1.** Acesse o seu Catálogo de Serviços no [**Portal de Parceiros**](https://partners.stackspot.com);  
**Passo 2.** Para solicitar acesso à uma API, siga os passos:

  1. Na subseção de **APIs**, clique na **API** que você quer ter acesso;
  2. Dentro da API, clique no botão **'Solicitar acesso'**;  
  3. Selecione as Aplicações da API que você quer ter acesso.
  4. Depois, clique no botão **'Solicitar acesso'**.

Pronto, você solicitou acesso à uma API. Agora você precisa ter a autorização do **owner** do Catálogo para utilizar a API.

**Passo 3.** Para solicitar acesso a um **Produto**, siga os passos:

  1. Na subseção de **Produtos**, clique no Produto que você quer ter acesso;
  2. Dentro do Produto, clique no botão **'Solicitar acesso'**;  
  3. Selecione as Aplicações do Produto que você quer ter acesso.
  4. Depois, clique no botão **'Solicitar acesso'**.

Pronto, você solicitou acesso a um Produto. Agora você precisa ter a autorização do **owner** do Catálogo para utilizar o Produto.
