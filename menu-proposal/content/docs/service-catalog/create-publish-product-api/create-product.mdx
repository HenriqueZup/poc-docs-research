> Nesta seção, você encontra como criar e publicar um produto no portal.

<br/> 

## **Criar um Produto**  

Você pode organizar e agrupar as APIs publicadas criando um Produto. Assim, você facilita a integração de APIs nas aplicações dos seus Parceiros.  

Entre no Dashboard do seu **Workspace** e siga os passos:

**Passo 1.** Acesse a subseção **'Produtos'**, no menu principal. Em seguida, clique no botão **'Criar Produto'**, no canto superior direito da tela;

**Passo 2.** Em **'Informação Básica'**, preencha os seguintes campos:

- **Nome**: insira o nome que você quer dar ao Produto.
- **Descrição**: dê uma breve descrição ao Produto.
- **Logo** (opcional)

Em seguida, clique no botão **'Próximo'**;

**Passo 3.** Na tela **'Adicionar APIs'**, clique no botão **'Adicionar APIs'** e selecione as APIs que você quer vincular ao seu Produto;

**Passo 4.** Já na tela **'Selecione ambiente'**, clique no botão **'Adicionar Ambiente'** e selecione os ambientes em que você quer associar às APIs;

**Passo 5.** Revise as informações e clique no botão **'Concluir'**.

Pronto, você criou um Produto.

## **Publicar um Produto**

Para **publicar um Produto**, siga os passos:

**Passo 1.** No Workspace em que você criou o seu Produto, acesse a seção de **Produtos**;

**Passo 2.** Clique no Produto que você criou e quer publicar;

**Passo 3.** Agora clique no botão **'Publicar Produto'**;

Pronto, você publicou um Produto no Catálogo.

## **Adicionar mais APIs no Produto**  

Para adicionar mais APIs a ele, siga os passos:

**Passo 1.** Dentro do seu Produto, acesse a subseção **'APIs'**;

**Passo 2.** Clique no botão **'Adicionar API'**;

**Passo 3.** Selecione as APIs e clique no botão **'Adicionar selecionado'**.

Pronto, você adicionou mais APIs no seu Produto.

## **Remover uma API do Produto**

Você pode remover uma ou mais APIs do seu Produto depois que ele foi publicado. Para isso, siga os passos:

**Passo 1.** Acesse o seu Produto e clique no botão de lixeira ao lado da API que você quer remover;

**Passo 2.** Para confirmar a remoção da API, clique em **'Confirmar remoção'**.

Pronto, você removeu uma API do seu Produto.

## **Despublicar ou Deletar um Produto**  

Para **deletar** um Produto, siga os passos. Esta é uma ação **irreversível**.

**Passo 1.** Clique na subseção **'Configurações'**;

**Passo 2.** Em seguida, clique no botão **'Deletar produto'**, localizada no fim da página;

**Passo 3.** Para confirmar, clique em **'Confirmar remoção'**.

Pronto, você deletou um Produto.

Para **despublicar** um Produto, siga os passos:

**Passo 1.** Clique na subseção **'Visão Geral'** do Produto;  

**Passo 2.** Agora, clique no botão **'Despublicar Produto'**;  

**Passo 3.** Para confirmar, clique em **'Despublicar Produto'**.

Pronto, você despublicou um Produto.
