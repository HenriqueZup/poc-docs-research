> Nesta seção, você encontra como criar uma Connection Interface de API Gateway.

<br/> 

Antes de **vincular** uma [**Connection Interface**](create-use/connections/connection-interface.mdx) de API Gateway na sua API, você precisa **criá-la no Workspace**.

Confira os passos:

**Passo 1.** Acesse o seu Workspace [**no Portal da StackSpot EDP**](https://app.stackspot.com/login);  

**Passo 2.** Clique na subseção **'Connection Interfaces'**, no menu principal da tela;  

**Passo 3.** Agora, clique na aba **'Criada por pessoas usuárias'**;  

**Passo 4.** Clique no botão **'Criar Connection Interface'**;  

**Passo 5.** Em **'Criar Connection Interface'**, informe os seguintes dados:  

- **Nome**: preencha como você quer nomear a Connection Interface.
- **Tipo de Conexão**: selecione a opção **`aws-api-gateway-rest-con`**. 

Depois disso, clique no botão **'Próximo'**.

**Passo 6.** Na tela de **'Parâmetros'**, inclua o **arn** e o **nome (name)** da sua Connection Interface. 

> Se você habilitar a opção **'Definir valores por ambiente'**, selecione os ambientes e inclua um **arn** e um **nome (name)** para cada um deles.

Para continuar, clique no botão **'Próximo'**.

**Passo 7.** Revise o **Resumo** e os **Parâmetros** e clique no botão **'Concluir'**.

Pronto, sua Connection Interface foi criada.
