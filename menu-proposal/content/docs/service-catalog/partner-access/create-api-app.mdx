> Nesta seção, você encontra como associar uma API em uma Aplicação criada.

<br/> 

No Catálogo de Serviços é possível adicionar uma API em uma Aplicação em execução. Ao associar uma API, você disponibiliza novos recursos e funcionalidades para os usuários da Aplicação.

Confira o passo a passo:  

**Passo 1.** Acesse a seção de **'Configurações'** da sua Aplicação;

**Passo 2.** Dentro de Configurações, em **'Definições de API'**, clique em **'Editar'** e preencha os seguintes campos:

- **Nome:** como você quer nomear a sua API.
- **Descrição:** dê uma breve descrição para a API.

Faça o upload do arquivo OpenAPI. São permitidas as extensões **.yaml**, **.yml** e **.json**.

Depois disso, insira a URL do Gateway.

> Neste passo é preciso incluir só uma URL do Gateway, porque a Aplicação já está em um ambiente específico.
