> Nesta seção, você encontra como vincular um produto ou uma API na conta do seu Parceiro.

<br/> 

Para vincular um **Produto** ou uma **API** na Conta do Parceiro, siga os passos:

**Passo 1.** Acesse a sua Conta [**no Portal da StackSpot EDP**](https://app.stackspot.com/login);  

**Passo 2.** Clique na subseção **'Parceiros'**, localizada na seção **'Configurações'**, no menu principal;  

**Passo 3.** Acesse a conta do Parceiro;  

**Passo 4.** Para adicionar um **Produto**, clique na subseção **'Produtos'** e siga os passos:

  1. Clique no botão **‘Adicionar Produto’**, no canto superior direito da tela;
  2. Selecione quais **Produtos** e os respectivos **Ambientes** que você irá disponibilizar para o seu parceiro;
  3. Para confirmar, clique no botão **‘Adicionar Produtos’**.  

**Passo 5.** Para adicionar uma **API**, clique clique na subseção **'APIs'** e siga os passos:

  1. Clique no botão **‘Adicionar API’**, no canto superior direito da tela;  
  2. Selecione quais **APIs** e os respectivos **Ambientes** que você irá disponibilizar para o seu parceiro;
  3. Para confirmar, clique no botão **‘Adicionar APIs’**.

Os serviços estão disponíveis na Conta do seu parceiro.
