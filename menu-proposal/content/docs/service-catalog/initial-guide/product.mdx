O Produto é um conjunto de APIs. É uma entidade exposta no Catálogo de Serviços que representa esse conjunto de APIs associadas.

![Tela de Produto no portal da StackSpot. Seção Catálogo de Serviços](/img/product.png)
> A imagem está em inglês.

:::tip Dica!
Você já pode usar no Produto as referências de API que já estão prontas.
:::

Quando um Produto é criado no Catálogo, ele pode ter três status:

1. **Rascunho (Draft)**: nesse status o Produto aparece no Catálogo de Serviços apenas para o Workspace dono do Produto. Ele pode ser publicado por qualquer membro da Equipe do Workspace da Conta e não é exibido no Catálogo para toda organização.

2. **Publicado (Published)**: o Produto é exibido no Catálogo para toda organização.

3. **Despublicado (Unpublished)**: nesse status o Produto para de ser exibido no Catálogo, mas pode ser publicado novamente.
