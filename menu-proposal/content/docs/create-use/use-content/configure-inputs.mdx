## **Visão Geral** 

Ao criar Aplicações e Infraestruturas no portal StackSpot EDP, você precisa preencher inputs de Plugins e Actions. Neste guia, você encontra as regras e outras informações sobre preenchimentos de inputs. Confira: 

## **Regras Gerais**

- Se existirem [**Contextos definidos**](home/account/organization/configure-context-account.mdx), algumas (ou todas) as variáveis já estarão preenchidas. E, quando as variáveis são mandatórias, você não consegue mudá-las.

- O **preenchimento de inputs** pode conter apenas caracteres alfanuméricos, sublinhado (_) e hífen (-), conforme o regex: **`^[a-zA-Z0-9_-]+$`**. Por exemplo: nome_Input, Nome_input, NOME_INPUT, Nome-input, nome-input, N0m3-1nput. 

- **Alias:** este campo serve para **nomear a utilização do Plugin** e indicar qual é o objetivo dele na Aplicação, pois Plugins podem ser **aplicados mais de uma vez**. Ele já **vem automaticamente preenchido, como mostra a imagem**, mas você pode **editá-lo**. Para isso, clique no campo e edite o texto. **O `alias` é imutável depois de configurado. Caso você queira editar este nome, esse é o único momento possível.**

- Para saber mais sobre **inputs de Plugin**, consulte o [**Guia de Inputs de Criadores de Conteúdo**](create-use/create-content/yaml-files/inputs.mdx).


## **Preencher inputs com Variáveis de Contas** 

**Ao aplicar um Plugin,** você pode escolher [**utilizar uma Variáveis de Contas**](home/account/organization/variables/create-variables.mdx) para preencher o valor de inputs do tipo texto. Para isso: 

1. Clique no **botão "Usar variável"** ao lado do campo do input; 
2. **Selecione uma das Variáveis** disponíveis que aparecem na lista;
3. Caso **não seja mandatório**, você pode alterar o valor da Variável.
