> Nesta seção, você encontra como deletar uma Connection Interface criada manualmente.

<br/>

Você pode deletar completamente uma Connection Interface criada manualmente. Siga os passos:

:::caution Cuidado!
Para deletar uma Connection Interface por completo, ela **não pode estar sendo utilizada**. 
:::

#### **Pré-requisitos**

- Ter uma [**conta StackSpot**](home/account/index.mdx);
- [**Ter papel de Account Holder, SysAdmin ou Account Admin**](home/account/organization/access-management/roles.mdx);
- A Connection Interface que você quer editar deve ter sido [**criada manualmente**](create-use/connections/connection-interface.mdx#criar-connection-interface-no-workspace-manualmente);

#### **Passo a passo**

**Passo 1.** Faça [**login na sua conta no Portal da StackSpot EDP**](https://app.stackspot.com/login) e clique em **'Workspaces'**;

**Passo 2.** Encontre o Workspace onde está a Connection Interface que você deseja deletar e acesse-o;

**Passo 3.** No menu principal, clique em **'Connection Interfaces'**;

**Passo 4.** Acesse a Connection Interface que você quer deletar;

**Passo 5.** Clique no botão **'Deletar Connection Interface'**.

Pronto, você deletou uma Connection Interface com sucesso.
