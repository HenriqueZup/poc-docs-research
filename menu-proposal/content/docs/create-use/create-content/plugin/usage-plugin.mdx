title: Insights de Uso do Plugin
description: Informações sobre onde o Plugin está sendo utilizado (ou não).
---

> Nesta seção, você encontra um guia de como visualizar o uso de um Plugin em uma Stack, Starter, Aplicação e/ou Infraestrutura. 

<br/>

Na StackSpot é possível visualizar como um Plugin está sendo usado e vinculado a outros conteúdos ou Aplicações e Infraestruturas, por exemplo. 

Para visualizar esses dados, siga os passos a seguir:

**Passo 1.** Acesse o seu **Estúdio**;

**Passo 2.** Clique no Plugin que você quer visualizar e, em seguida, na seção **’Insights de Uso’**;

Pronto, você pode visualizar os conteúdos vinculados a um Plugin.

Dentro desta seção, você pode visualizar as seguintes subseções:

#### **Stacks**

É possível visualizar em quais Stacks a versão de um Plugin está vinculada. Para conferir os detalhes de uso, clique na Stack que você quer visualizar.

Dentro da Stack, você encontra informações como:

- **Versão da Stack**: quais versões da Stack estão usando uma versão do Plugin.

- **Versão do Plugin**: quais versões do Plugin estão sendo usadas em uma versão da Stack.

:::tip Dica!

[**Confira as regras para versionar, depreciar e despublicar um Plugin em uma Stack**](create-use/create-content/plugin/plugin-version.mdx).

:::

Para **depreciar a versão** selecionada, clique no ícone ao lado da versão e, logo em seguida, no botão **'Depreciar versão'**. Agora siga os passos a seguir:

**Passo 1.** Selecione o motivo: escolha entre **Falta de manutenção**, **Problemas de segurança**, **Bugs** ou **Outro**; 

**Passo 2.** Escreva a palavra **DEPRECATE** no campo de texto para confirmar a depreciação; 

**Passo 3.** Clique no botão **'Depreciar versão do Plugin'**.

Pronto, você depreciou a versão de um Plugin em uma Stack.

#### **Plugins** 

Nesta subseção você pode visualizar quais outros Plugins estão solicitando o uso do Plugin em questão. Para conferir os detalhes de uso, clique no Plugin que você deseja visualizar.

Dentro do Plugin, você vai encontrar as seguintes informações:

- **Versão do Plugin**: quais versões do Plugin estão sendo requisitadas em outros Plugins

- **Tipo do Plugin**: ele pode ser do tipo App (Aplicação) ou Infra (Infraestrutura).

- **Estúdio**: em qual Estúdio o Plugin está publicado.

- **Versões Vinculadas**: em quais ou quantas versões o Plugin está vinculado. 

Para **depreciar a versão** selecionada, clique no ícone ao lado da versão e, logo em seguida, no botão **'Depreciar versão'**. Agora siga os passos a seguir:

**Passo 1.** Selecione o motivo: escolha entre **Falta de manutenção**, **Problemas de segurança**, **Bugs** ou **Outro**; 

**Passo 2.** Escreva a palavra **DEPRECATE** no campo de texto para confirmar a depreciação; 

**Passo 3.** Clique no botão **'Depreciar versão do Plugin'**.

#### **Workflows (Versão Beta)** 

Nesta subseção você pode visualizar quais outros [**Workflows (Versão Beta)**](beta-version\workflow-beta\index.mdx) estão solicitando o uso do Plugin em questão. Para conferir os detalhes de uso, clique no Workflow que você deseja visualizar.

Dentro do Workflow, você vai encontrar as seguintes informações:

- **Versão do Plugin**: quais versões do Plugin estão sendo requisitadas em outros Workflows.

- **Versões Vinculadas**: em quais ou quantas versões o Workflow está vinculado. 

Para **depreciar a versão** selecionada, clique no ícone ao lado da versão e, logo em seguida, no botão **'Depreciar versão'**. Agora siga os passos a seguir:

**Passo 1.** Selecione o motivo: escolha entre **Falta de manutenção**, **Problemas de segurança**, **Bugs** ou **Outro**; 

**Passo 2.** Escreva a palavra **DEPRECATE** no campo de texto para confirmar a depreciação; 

**Passo 3.** Clique no botão **'Depreciar versão do Workflow'**.

#### **Starters**  

É possível visualizar, dentro de uma Stack, quais versões de um Plugin o Starter está vinculado. Para conferir os detalhes de uso, clique no **Starter** que você quer visualizar.

Dentro do Starter, você vai encontrar informações como:

- **Nome do Starter**

- **Tipo**: pode ser App (Aplicação) ou Infra (Infraestrutura).

- **Versão da Stack**: em quais versões da Stack este Starter está sendo usado. 

- **Versão do Estúdio**: quais versões deste Starter estão em um Estúdio.


#### **Infraestrutura**

É possível visualizar quais Infraestruturas o Plugin está sendo usado. Para conferir os detalhes de uso por versão do Plugin, clique na **Infraestrutura** que você quer visualizar.

Dentro da Infraestrutura, você vai encontrar informações como:

- **Versão do Plugin**: quais versões do Plugin estão sendo utilizadas na Infraestrutura.

- **Workspace**: em quais Workspaces o Plugin está sendo usado

- **Versões relacionadas**: em quais versões esse Plugin está interligado. 

Para **depreciar a versão** selecionada, clique no ícone ao lado da versão e, logo em seguida, no botão **'Depreciar versão'**. Agora siga os passos a seguir:

**Passo 1.** **Selecione o motivo**: escolha entre **Falta de manutenção**, **Problemas de segurança**, **Bugs** ou **Outro**; 

**Passo 2.** Escreva a palavra **DEPRECATE** no campo de texto para confirmar a depreciação; 

**Passo 3.** Clique no botão **'Depreciar versão do Plugin'**.


#### **Aplicações**

Também é possível visualizar quais Aplicações o Plugin está sendo usado. Para conferir os detalhes de uso por versão do Plugin, clique na **Aplicação** que você quer visualizar.

Dentro da Aplicação, você vai encontrar informações como:

- **Versão do Plugin**: quais versões do Plugin estão sendo utilizadas na Aplicação.

- **Workspace**: em quais Workspaces o Plugin está sendo usado

- **Versões relacionadas**: em quais versões esse Plugin está interligado. 

#### **Fora de uso**

Nesta seção, você pode visualizar quais versões do Plugin **não estão** sendo usadas em nenhum lugar na StackSpot.

Além disso, também é possível depreciar a versão de um Plugin que não está sendo utilizada. Para fazer isso, siga os passos abaixo:

**Passo 1.** Na linha da versão do Plugin que você quer depreciar, clique no ícone da coluna **'Gerenciar versão'**;

**Passo 2.** Na tela exibida, clique no botão **'Depreciar versão'**.

Pronto, você depreciou a versão de um Plugin que não está sendo utilizado.
