## **O que são os arquivos .yaml?**

São os arquivos que contêm todas as configurações das estruturas geradas pelo desenvolvedor ao criar:

- **Plugins**
- **Actions** 
- **Starters**
- **Arquivos de especificação (spec file)**
- **Aplicações** 
- **Infraestruturas**

Para alguns destes arquivos de configuração, há recursos que permitem editar comportamentos e informações para criar conteúdo para a StackSpot.
