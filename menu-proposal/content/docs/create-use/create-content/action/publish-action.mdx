> Nesta seção, você encontra um guia de como publicar uma Action usando o STK CLI.

<br/>

Publicar na StackSpot significa armazenar e disponibilizar os conteúdos das Stacks, Plugins e Actions na plataforma da StackSpot para que outras pessoas desenvolvedoras  possam usá-los. Você gerencia quem pode acessar o que você publica através das configurações de visibilidade do seu Estúdio.

:::caution Cuidado!

Para publicar uma Action, confira se o Slug (Identificador) é único dentro do Estúdio. Não é possível ter um mesmo Slug, ou seja com a mesma identificação (seja de Stack, Plugin ou Action) em um Estúdio.

:::

## **Pré-requisitos**

- [**STK CLI**](home/stk-cli/install.mdx).  
- Já ter [**criado uma Action**](create-use/create-content/action/run-action.mdx).


:::danger Atenção!  

Para publicar uma Action, você precisa ter [**permissão**](/home/account/organization/access-management/roles.md ) de **Criação e Edição de conteúdos**.

:::

1. Na pasta da sua Action, execute o comando [**stk publish action**](home/stk-cli/commands/action-commands.md#stk-publish-action):

```bash
stk publish action
```

2. Selecione o Estúdio no terminal ou informe para qual Estúdio você deseja publicar a Action, utilize a opção **`--studio`**.

Exemplo:

```bash
stk publish action --studio my-studio-name
```
