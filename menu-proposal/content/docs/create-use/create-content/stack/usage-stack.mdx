> Nesta seção, você encontra um guia de como visualizar o uso de uma Stack em um Workspace, Aplicação e/ou Infraestrutura.  

<br/>

Na StackSpot é possível visualizar como as versões de uma Stack estão sendo usadas e vinculadas a outros conteúdos ou Aplicações e Infraestruturas, por exemplo. 

### **Dados das versões**

Para visualizar os **dados das versões** da Stack, **depreciá-las** ou **despublicá-las**, siga os seguintes passos: 

**Passo 1.** Acesse o seu Estúdio;

**Passo 2.** Na tela de **'Visão Geral'**, clique no botão **'Gerenciar Versão'**;

**Passo 3.** Em **'Gerenciar Versão'** você pode visualizar os status das versões da Stack nas seguintes abas:



### **Conteúdos vinculados**   

Para visualizar os dados de **conteúdos vinculados** a uma Stack, siga o passo a seguir:

Clique na Stack que você quer visualizar e, em seguida, na seção **’Insights de Uso’**;

Pronto, você pode visualizar os conteúdos vinculados a uma Stack.

Dentro desta seção, você pode visualizar as seguintes subseções: **Workspace** e **Sem uso**. 

### **Workspace**

É possível visualizar em quais Workspaces a versão da Stack está sendo usada. Para verificar os detalhes de uso, clique no Workspace que você deseja.

Dentro dele, você vai encontrar informações como:

- **Versão da Stack**: quais versões da Stack estão sendo utilizadas no Workspace.

- **Ambiente**: os ambientes da Conta em que as versões estão publicadas. 

- **Utilizada em**: em quais e em quantas Infraestruturas e/ou Aplicações a versão está sendo usada. 

Além disso, você depreciar ou despublicar a versão de uma Stack que não está sendo utilizada. 

Para **depreciar a versão** selecionada, clique no ícone ao lado da versão e, logo em seguida, no botão **'Depreciar versão'**. Agora siga os passos a seguir:

**Passo 1.** **Selecione o motivo**: escolha entre **Falta de Manutenção**, **Problemas de Segurança**, **Bugs** ou **Outro**; 

**Passo 2.** Escreva a palavra **DEPRECATE** no campo de texto para confirmar a depreciação; 

**Passo 3.** Clique no botão **'Depreciar versão da Stack'**.

Para **despublicar a versão** selecionada, clique no ícone ao lado da versão e, logo em seguida, no botão **'Despublicar versão'**. Agora siga os passos a seguir:

**Passo 1.** Escreva a palavra **UNPUBLISH** no campo de texto para confirmar a despublicação;

**Passo 2.** Clique no botão **'Despublicar versão da Stack'**.
