> Nesta seção, você encontra o que são Stacks.

<br/>

A Stack é um agrupador de tecnologias necessárias para uma Aplicação existir, que pode ser desde do código até a Infraestrutura utilizada para prover a aplicação.

A ideia é englobar os seguintes conceitos:

- Código da aplicação;  
- Código de infra, ou seja, onde a Stack vai ser provisionada (Cloud, servidor local, etc).

O objetivo da Stack é facilitar a vida da pessoa desenvolvedora para que foque apenas no desenvolvimento das regras de negócios da aplicação, não sendo mais necessário tanto esforço para configurar frameworks ou infraestruturas.

Uma Stack permite você:

- Adicionar Plugins;  
- Criar Starters.

:::info  Informação Adicional

Stacks estão dentro de cada Conta e qualquer pessoa que tenha acesso a StackSpot pode criá-las e versioná-las.  

:::
