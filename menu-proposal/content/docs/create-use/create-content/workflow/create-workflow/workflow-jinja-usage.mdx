### **Uso de expressões  JINJA**

O uso de Jinja na StackSpot se estende agora para os Workflows. Você pode usar expressões como variáveis para os **`inputs`**, **`outputs`** e **`computed-inputs`** das Actions, Plugins e Workflows. [**Para mais informações, acesse a página sobre o uso de Jinja na StackSpot**](create-use/create-content/yaml-files/jinja.mdx).
