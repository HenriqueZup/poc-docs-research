> Nesta seção, você encontra os passos para repetir a execução de Jobs de um Workflow da SackSpot.

:::warning Atenção!

Os passos mencionados neste guia funcionam **apenas para os Jobs de Workflows da StackSpot**. Os outros Workflows do seu SCM **não são afetados** por esta funcionalidade.

:::

Logo após executar um Workflow, seja para criar uma Aplicação ou executar um deploy, você tem acesso ao fluxo do Workflow sendo executado. Nesta tela são exibidos todos os Jobs, steps e detalhes da execução do Workflow.  
Agora é possível fazer novas tentativas de execução dos Jobs de um mesmo Workflow com o botão de **Re-run jobs**.

## **Re-run jobs**

Este botão oferece duas opções para repetir a execução dos Jobs do seu Workflow da StackSpot:

- **Re-run all jobs**: esta opção executa novamente todos os Jobs do seu Workflow a qualquer momento;

- **Re-run failed jobs**: esta opção executa **todos** os Jobs que falharam a partir do primeiro Job que falhou. Não é possível executar um Job que falhou de forma isolada.

## **Attempts**

A partir da primeira execução, seja de todos os Jobs ou apenas os que falharam, cada tentativa gera um novo log da execução do Workflow chamado **Attempt**.   
Cada **Attempt** possui o log da execução dos Jobs do Workflow e ficam disponíveis para consulta e navegação entre os logs sem interferir na execução atual do Workflow.
