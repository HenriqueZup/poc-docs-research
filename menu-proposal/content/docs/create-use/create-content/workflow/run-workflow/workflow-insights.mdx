> Nesta seção, você encontra detalhes sobre o Insights do StackSpot Workflow.

<br/>

Com a adição do StackSpot Workflow, [**o menu de Insights disponível no seu Estúdio**](create-use\studio\insights.mdx) agora mostra os dados dos conteúdos relacionados ao seu Workflow na StackSpot.

## **Consultar Insights**

Para acessar a tela de Insights siga os passos a seguir:

**Passo 1.** Acesse o Portal da StackSpot EDP;  
**Passo 2.** Clique o menu **Estúdios**;  
**Passo 3.** Em **‘Conteúdo‘** no seu Estúdio, clique na aba **‘Workflows‘** para visualizar os Workflows publicados no seu Estúdio;  
**Passo 4.** Clique no Workflow que você deseja visualizar os Insights;  
**Passo 5.** Clique no menu **‘Insights de Uso‘**.  

<br/>

A tela de "Insights de Uso" irá exibir três abas com as seguintes informações:

### **Aba 'Stacks'**

Nesta aba você visualiza uma lista com todas as Stacks que possuem o Workflow que você selecionou no Estúdio. 

| **Nome** | **Versões Vinculadas** | 
| ---               | ---                    |
| Lista com o nome da Stack que contém o Workflow. | Número da quantidade de versões deste Workflow vinculado a essa Stack. |

Ao clicar em uma Stack da lista, são exibidas as seguintes informações:

| **Versão do Workflow** | **Versão da Stack** | 
| ---               | ---                    |
| Lista de cada versão do Workflow vinculada à Stack. Exemplo: `1.0.2`, `1.0.3`, `1.0.4`. | Lista de cada versão da Stack vinculada a cada versão do Workflow. Exemplo: `1.2.0`, `1.3.0`, `1.4.0`. Você também acesso ao botão de ação para ver detalhes ou depreciar a versão do Workflow. |

### **Aba 'Workflows'**

Nesta aba você visualiza todos os Workflows que utilizam o Workflow que você selecionou. Os Workflows são exbidos em uma lista com as seguintes informações:

| **Nome** | **Tipo**| **Versões Vinculadas** | 
| ---               | --- |  ---                    |
| Lista com o nome de cada Workflow que utiliza o Workflow selecionado. | O tipo de cada Workflow que utiliza o Workflow selecionado.  | Quantidade de versões deste Workflow vinculadas ao Workflow selecionado. |

Ao clicar no Workflow você encontra as versões vinculadas e o botão de ação para ver detalhes de cada versão vinculada.

### **Aba 'Sem Uso'**

Nesta aba você visualiza todas as versões do Workflow selecionado que não estão sendo utilizados por nenhum outro [**Conteúdo da StackSpot**](home\stackspot\glossary.md#content), Aplicação ou Infraestrutura. Na lista você encontra a versão que não é usada e o botão de ação para ver detalhes, depreciar ou despublicar a versão do Workflow.
