> Nesta seção, você encontra a descrição de uma Action que customiza o sumário das informações do Workflow. 


## **Pré-requisitos**

- StackSpot CLI instalado e atualizado.  
- Ter acesso a um Estúdio com Workflows publicados.

## **Customizar um Sumário**

Através de uma Action, é possível customizar um sumário do Workflow de acordo com as informações que você quer que sejam exibidas. 


Confira a seguir alguns exemplos de informações que podem ser customizadas no sumário:

- Action
- Status
- Environment
- Workspace
- Runner
- Image

Para customizar o sumário do Workflow, execute o comando a seguir:

```bash title="Comando para customizar um sumário no Workflow"
stk run action stackspot-core/stackspot-workflow-summary@1
```

A Action tem os seguintes inputs obrigatórios:

| **Input**         | **Descrição**                                                                 | **Tipo**   | 
|--------------------|---------------------------------------------------------------------------------|------------|
| `title`           | O título do sumário do Workflow.                                            | `string`   | 
| `message`         | A mensagem que será incluída no sumário do Workflow.                              | `string`   |     

Para usar a Action, os inputs **`title`** e **`message`** devem, obrigatoriamente, ser especificados no `yaml`. 

Confira um exemplo de utilização da Action no Workflow:

```yaml
schema-version: v1
kind: workflow
metadata:
  name: update-workflow-summary
  display-name: Update workflow Summary
  description: Updates the workflow summary for a workflow execution.
  version: 1.0.0
spec:
  type: deploy
  label: Update workflow Summary
  jobs:
    - id: update_summary
      label: Update workflow Summary
      steps:
        - id: update_summary_step
          label: Update Summary
          name: "stackspot-core/update-workflow-summary@1"
          type: action
          inputs:
          // new-line-start
            title: "workflow Completed"
            message: "The workflow was successfully completed."
          // new-line-end
```
