## **Insights: Painel de dados personalizável**

O Insights é um painel de dados da plataforma que pode ser personalizado e automatizado. Ele permite que você adicione ou remova painéis e navegue por gráficos relacionados a entidades como Plugins e Stacks.

No painel de Insights, você pode realizar as seguintes ações:

- Visualizar os dados em formato de gráfico;
- Filtrar os gráficos para destacar as informações que você precisa;
- Excluir gráficos que não são mais necessários.

### **Gráficos disponíveis**

Você tem acesso a gráficos com informações gerais, como:

#### 1. **Execuções do Comando Apply Plugin**

- **Quantidade de `apply plugin` por mês:** este gráfico mostra a contagem de execuções do comando [**`stk apply plugin`**](home/stk-cli/commands/plugin-commands.md#stk-apply-plugin) para cada Plugin do Estúdio, organizadas por mês.

#### 2. **Aplicações (Apps)**

- **Quantidade de `create app` por mês:** este gráfico exibe a contagem de execuções do comando [**`stk create app`**](home/stk-cli/commands/application-commands.md#stk-create-app), organizadas por Starters das Stacks de um Estúdio, por mês.

- **Quantidade de `create infra` por mês:** este gráfico apresenta a contagem de execuções do comando [**`stk create infra`**](home/stk-cli/commands/infraestructure-commands.md#stk-create-infra), organizadas por Stacks de infraestrutura de um Estúdio, por mês.

## **Como acessar os dados**

Siga os passos a seguir para acessar as informações no painel de Insights:

1. No seu Estúdio, clique no botão **‘Insights’**;  
2. Agora, clique no botão **‘Adicionar painel de dados’**;  
3. Escolha o gráfico de dados que deseja visualizar.

---

## **Como baixar os dados**

Você pode baixar um arquivo no formato **.csv** com todos os dados exibidos no painel de Insights. Para isso:

1. Acesse o seu Estúdio;
2. Clique no botão **‘Insights’**; 
3. Agora, clique no botão **‘Baixar dados do Estúdio’**.

Pronto, você pode analisar os dados no formato baixado.
