> Nesta seção, você encontra detalhes sobre os Estúdios.

<br/>

Estúdio é uma entidade que gerencia a criação e distribuição de Stacks e seus Plugins. Ele auxilia o **usuário com permissão de Criador** a ter uma marca para apoiar o trabalho. Além disso, em um Estúdio é possível associar Equipes e configurar diferentes visibilidades.

## **Conceitos que fazem parte do funcionamento do Estúdio**  

- [**Slugs:**](create-use/studio/slugs.mdx) são os identificadores únicos para as Contas, Estúdio, Stacks e Plugins e compõem as URLs da StackSpot.  

- [**Plugin:**](create-use/create-content/plugin/create-plugin.mdx) é como um building block que adiciona novas capacidades a uma Aplicação. Um Plugin sempre está associado a um Estúdio.

- [**Action:**](create-use/create-content/action/actions.mdx) uma forma de executar automações de forma remota ou local.

- [**Stacks:**](create-use/create-content/stack/create-stack.mdx) são agrupamentos de Plugins. A Stack provê recursos adequados que a pessoa desenvolvedora precisa para criar uma Aplicação.  

- [**Arquivos .yaml:**](create-use/create-content/yaml-files/intro-yaml.mdx) detalhes dos arquivos YAML, Inputs, Inputs Avançados, Hooks Declarativos, Metadata e Jinja na StackSpot.

## **O que você pode fazer no Estúdio**

- Criar e publicar Plugin;  
- Publicar e validar uma Action. E associá-la a um Plugin de Infra;  
- Criar e adicionar Plugin, Starter e Link em uma Stack;  
- Consultar a versão da Stack e publicar uma nova;  
- Criar e configurar Slugs;  
- [**Configurar sugestões de Connection Interfaces**](create-use/connections/connection-interface-suggestion.mdx);  
- Configurar os arquivos .yaml;  
- Visualizar os Insights dos conteúdos para acompanhar os dados do progresso e evolução do que foi criado, publicado, aplicado e registrado;
- Você pode conferir as informações gerais e deletar o seu Estúdio.
