## **Como usar o Glossário**

Encontre aqui os termos técnicos usados na StackSpot, com traduções para o português (quando necessário) e exemplos de uso. Antes de aplicar um termo, confira se ele deve ser usado em inglês ou português, de acordo com o padrão da documentação.
____

## **Account**

- **Termo em português:** Conta
- **Definição:** conta da organização (Enterprise) conectada ao GitHub.
- **Exemplo:** “A Conta Enterprise permite que a organização configure e gerencie funcionalidades específicas“.

____

## **Account Admin**

- Use o termo em inglês.
- **Definição:** pessoa com privilégios administrativos em uma conta StackSpot.
- **Exemplo:** “Defina permissões de acesso específicas para diferentes para pessoas usuárias como um Account Admin“.

____

## **Account holder**

- Use o termo em inglês. 
- **Definição:** pessoa responsável por uma conta ou com permissões administrativas amplas na plataforma.
- **Exemplo:** “Dê privilégios de administração a um account holder para gerenciar contas na plataforma“.

____

## **Action**

- Use o termo em inglês.
- **Definição:** executa automações de forma remota ou local para otimizar processos.
- **Exemplo:** “As Actions permitem automatizar processos repetitivos e integrar diferentes sistemas, facilitando o trabalho da pessoa desenvolvedora ao executar comandos e tarefas de forma eficiente“.

____

## **Application**

- **Termo em português:** Aplicação
- **Definição:** projeto de código criado e gerenciado em um Ambiente através da StackSpot.
- **Exemplo:** “Aplicações utilizam recursos e Plugins da StackSpot para criar projetos de forma rápida e padronizada“.

____

## **Appearance**

- Use o termo em inglês.
- **Definição:** opções de personalização, como modos claro e escuro e seleção de idioma, na plataforma.
- **Exemplo:** “Personalize a aparência da plataforma, incluindo modos claro e escuro para uma experiência confortável“.

____

## **Auto-Reconciliation**

- **Termo em português:** Reconciliação Automática
- **Definição:** comparação e ajuste de registros para garantir a precisão dos dados.
- **Exemplo:** “Compare registros de banco de dados para reconciliar dados entre servidores“.

____

## **Cloud**

- **Termo em português:** Nuvem
- **Definição:** computação remota que oferece armazenamento e processamento via internet.
- **Exemplo:** “Conecte uma conta de Nuvem para fazer deploy de aplicações na StackSpot“.

____

## **Cloud Provider**

- **Termo em português:** Provedor da Nuvem
- **Definição:** empresas que oferecem serviços de computação, armazenamento e aplicativos pela internet, como AWS, Microsoft Azure e Google Cloud.
- **Exemplo:** “Configure uma conta de Provedor de Nuvem para fazer deploy de suas aplicações na StackSpot“.

____

## **Cloud Services**

- Use o termo em inglês.
- **Definição:** solução para executar e gerenciar aplicações na nuvem, oferecendo análise, segurança e otimização.
- **Exemplo:** “A StackSpot Cloud Services oferece uma solução completa para executar e gerenciar suas aplicações na nuvem“.

____

## **Connection Interface**

- Use o termo em inglês.
- **Definição:** define os parâmetros necessários para que recursos de nuvem se conectem e sejam compatíveis entre si.
- **Exemplo:** “Crie uma Connection Interface no Workspace para conectar um recurso de nuvem existente“.

____

## **Connection Interface Type**

- Use o termo em inglês.
- **Definição:** define um padrão de atributos para garantir a compatibilidade entre componentes de nuvem.
- **Exemplo:** “O uso de Connection Interface Types facilita a integração de recursos, garantindo compatibilidade“.

____

## **Content**

- **Termo em português:** Conteúdo
- **Definição:** itens criados pelo StackSpot Engine, como Stacks, Starters, Plugins e Actions, focados em reutilização.
- **Exemplo:** “Desenvolva Conteúdos como Plugins e Stacks em Studios e use-os para criar aplicações em Workspaces“.

____

## **Context**

- **Termo em português:** Contexto
- **Definição:** valores pré-definidos para inputs de Plugins e Actions, configurados para padronizar o desenvolvimento.
- **Exemplo:** “Defina o Contexto de uma Stack Python a nível de Conta para padronizar os inputs“.

____

## **Contexto de Workflow**

- **Definição:** no Portal StackSpot EDP, o Contexto de Workflow define os valores dos inputs das Actions em um Workflow.
- **Exemplo:** “Ao criar uma aplicação no Portal, os valores dos inputs das Actions são configurados pelo Contexto de Workflow específico para criação de aplicações“.

____

## **Dashboard**

- Use o termo em inglês.
- **Definição:** interface visual que apresenta informações resumidas e métricas importantes.
- **Exemplo:** “Use um dashboard para monitorar o desempenho da Nuvem em tempo real“.

____

## **Deploy**

- Use o termo em inglês.
- **Definição:** processo de colocar uma aplicação ou atualização em produção.
- **Exemplo:** “Realize o deploy da sua aplicação na StackSpot para disponibilizá-la em um ambiente de produção com todos os recursos de infraestrutura provisionados“.

____

## **Dev**

- **Termo em português:** Pessoa Desenvolvedora
- **Definição:** abreviação para pessoa que desenvolve, responsável por criar e manter aplicações e sistemas.
- **Exemplo:** “Devs estão trabalhando em novos recursos para a próxima versão da Aplicação“.

____

## **Drift**

- **Termo em português:** Desvio
- **Definição:** diferença entre a configuração atual e a planejada de um sistema, geralmente causada por mudanças não registradas no código central.
- **Exemplo:** “O desvio ocorre quando uma mudança urgente é feita diretamente no servidor de produção sem atualizar o código no repositório central, criando diferenças entre os ambientes“.

____

## **DynamoDB Repository**

- Use o termo em inglês.
- **Definição:** mecanismo de armazenamento NoSQL usando Amazon DynamoDB, conhecido por sua escalabilidade e baixa latência.
- **Exemplo:** “O projeto usa um DynamoDB Repository para armazenar e consultar dados de forma escalável e eficiente“.

____

## **Environment**

- **Termo em português:** Ambientes 
- **Definição:** agrupa aplicações e recursos de nuvem para facilitar a organização e identificação.
- **Exemplo:** “A criação de Ambientes é essencial para organizar e isolar diferentes fases do ciclo de desenvolvimento, garantindo que as configurações e dados de um Ambiente não interfiram em outro“.

____

## **Guard Rails**

- Use o termo em inglês.
- **Definição:** políticas e configurações em ambientes de nuvem para garantir segurança e conformidade.
- **Exemplo:** “Os guard rails asseguram que as operações na nuvem sigam práticas de segurança e conformidade“.

____

## **Infrastructure**

- **Termo em português:** Infraestrutura
- **Definição:** conjunto de recursos criados por Stacks e Plugins de Infraestrutura para gerenciar e escalar aplicações.
- **Exemplo:** “A Infraestrutura na StackSpot otimiza recursos e facilita a gestão entre várias Aplicações“.

____

## **Insights**

- Use o termo em inglês.
- **Definição:** painel de dados customizável que facilita a visualização e análise de informações.
- **Exemplo:** “Use insights do painel para identificar tendências e tomar decisões estratégicas“.

____

## **Mandatory**

- **Termo em português:** Mandatório/Mandatória 
- **Definição:** algo que é obrigatório por regulamentações, padrões ou políticas da organização.
- **Exemplo:** “A conformidade com as normas de segurança é mandatória para todas as operações“.

____

## **Permissions**

- **Termo em português:** Permissões
- **Definição:** define quais ações podem ser realizadas em recursos dentro da plataforma.
- **Exemplo:** “Para criar um Plugin, você precisa de permissões específicas em um Estúdio“.

____

## **Plugin**

- Use o termo em inglês.
- **Definição:** adiciona capacidades a uma Aplicação, seguindo padrões e boas práticas.
- **Exemplo:** “Plugins ampliam as funcionalidades da aplicação, permitindo uma personalização modular“.

____

## **Reconciliation**

- **Termo em português:** Reconciliação
- **Definição:** comparação e ajuste de registros para garantir a precisão dos dados.
- **Exemplo:** “Compare registros de banco de dados para reconciliar dados entre servidores.“.

____

## **Relational Repository**

- Use o termo em inglês.
- **Definição:** sistema de armazenamento de dados em tabelas relacionais, usando SQL para manipulação e consulta.
- **Exemplo:** “O projeto envolve a criação de um Relational Repository para armazenar e acessar dados com eficiência usando SQL“.

____

## **Required**

- **Termo em português:** Requerido
- **Definição:** algo necessário ou obrigatório para alcançar um objetivo específico.
- **Exemplo:** “O preenchimento dos campos obrigatórios é requerido para concluir o registro com sucesso“.

____

## **Rollback**

- Use o termo em inglês.
- **Definição:** processo de reverter um sistema ou aplicação ao estado anterior após uma atualização ou deploy com erro.
- **Exemplo:** “Após um deploy com erro, faça o Rollback para restaurar a aplicação ao estado anterior“.

____

## **Saving Plans**

- Use o termo em inglês.
- **Definição:** programas que oferecem descontos em troca de um compromisso de gastos regulares com provedores de nuvem.
- **Exemplo:** “Os Saving Plans ajudam a economizar dinheiro na nuvem com descontos por compromissos de gastos“.

____

## **Slug**

- **Termo em português:** Identificadores Únicos.
- **Definição:** versão amigável de um texto para URL, usada para tornar endereços web mais legíveis.
- **Exemplo:** “Crie slugs significativos para URLs dos conteúdos na StackSpot“.

____

## **Spring Boot Microservice**

- Use o termo em inglês.
- **Definição:** componente independente desenvolvido com Spring Boot, focado em uma única funcionalidade dentro de uma arquitetura de microsserviços.
- **Exemplo:** “A equipe está criando um Microsserviço Spring Boot para gerenciar a autenticação de pessoas usuárias“.

____

## **Stack**

- Use o termo em inglês.
- **Definição:** conjunto de Plugins que fornece as tecnologias necessárias para criar uma Aplicação.
- **Exemplo:** “A Stack agrupa tecnologias e Plugins necessários, facilitando a criação de Aplicações“.

____

## **StackSpot AI Assistant**

- **Termo em português:** Assistente da StackSpot AI
- **Definição:** ferramenta AI-First que eleva a qualidade do código e agiliza o desenvolvimento, oferecendo suporte direto na IDE.
- **Exemplo:** “Quem usa o StackSpot AI Assistant realiza análises de código de forma mais eficiente“.

____

## **StackSpot Cloud Services**

- Use o termo em inglês.
- **Definição:** fornece ferramentas para processamento em nuvem com alto desempenho e escalabilidade.
- **Exemplo:** “StackSpot Cloud Services simplifica a gestão da infraestrutura de nuvem, permitindo foco no desenvolvimento“.

____

## **StackSpot Runtime Engine**

- Use o termo em inglês.
- **Definição:** gerencia o provisionamento de recursos de nuvem e configura a infraestrutura necessária para aplicações.
- **Exemplo:** “A StackSpot Runtime Engine reduz a complexidade ao gerenciar configurações de infraestrutura“.

____

## **Starter**

- Use o termo em inglês.
- **Definição:** conjunto pré-definido de Plugins que serve como um ponto de partida para criar uma Aplicação.
- **Exemplo:** “Use um Starter para aplicar uma combinação de Plugins já configurada ao criar uma Aplicação“.

____

## **Estúdio**

- **Definição:** permite a criação e distribuição centralizada de software, como Plugins e Actions.
- **Exemplo:** “Para distribuir conteúdos na StackSpot como Plugins e Actions, use um Estúdio para gerenciar os conteúdos publicados na sua conta StackSpot“.

____

## **Equipes**

- **Definição:** grupos de pessoas designados para criar e usar conteúdo em espaços como Studios e Workspaces.
- **Exemplo:** “As Equipes colaboram e produzem conteúdo em Studios e Workspaces“.

____

## **Pessoa usuária**

- **Definição:** pessoa que utiliza um produto ou serviço.
- **Exemplo:** “Realize testes de usabilidade como uma pessoa usuária para encontrar melhorias na StackSpot“.

____

## **Username**

- Use o termo em inglês.
- **Definição:** nome único usado para identificar e autenticar uma pessoa no sistema, essencial para acesso e segurança.
- **Exemplo:** “O username é essencial para acessar sua conta e realizar atividades na plataforma“.

____

## **Workspace**

- Use o termo em inglês.
- **Definição:** ambiente configurável onde pessoas desenvolvedoras acessam e utilizam conteúdos específicos para criar e implantar aplicações.
- **Exemplo:** “A criação de Workspaces permite padronizar e organizar o desenvolvimento e a implantação de Aplicações, facilitando o trabalho da pessoa desenvolvedora e SREs ao utilizar conteúdos pré-configurados“.

____
