---
title: Atualizar o STK CLI
description: Como atualizar o STK CLI.
---

> Nesta seção, você encontra como atualizar o STK CLI.

<br/>

Se você já utiliza a versão 4.5.x do STK CLI, é necessário fazer a atualização para a nova versão.
Confira:

**Passo 1.** No seu terminal, execute o comando:

```bash
stk upgrade --force 
```

**Passo 2.** Para confirmar a atualização, execute:

```bash
stk --version
```

O output do CLI é:

```bash
StackSpot version: 1.0
stk cli version: 5.0.5
```
