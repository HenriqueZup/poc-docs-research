> Nesta seção, você encontra os passos para deletar um Workflow.  

<br/>

:::danger Atenção!

Este conteúdo está sendo descontinuado, [**conheça o novo Workflow da StackSpot**](create-use/create-content/workflow/overview/index.mdx).

:::

:::caution Cuidado! 

- **Se você deletar um Workflow Padrão**: as Stacks que estavam associadas ao Workflow deletado ficarão sem nenhum Workflow. 
- **Se você deletar um Workflow de Stacks Específicas:** as Stacks automaticamente passarão a utilizar o Workflow padrão da conta, caso exista um.

::: 

**Passo 1.** [**Faça login no Portal StackSpot EDP**](https://app.stackspot.com/login) e clique no botão **'Organização'**; 

**Passo 2.** Clique no botão **'Workflow'**; 

**Passo 3.** Selecione o Workflow que você quer editar; 

**Passo 4.** Clique em **'Configurações'**; 

**Passo 5.** No final da tela, clique no botão **'Deletar Workflow'**.
