## **Gerar as chaves do Token de Acesso Pessoal (PAT)**

A StackSpot gera para você, como usuário, um Token de Acesso, o **PAT** (Personal Access Token). Com isso, você pode executar os serviços da StackSpot utilizando um **`client id`** e um **`client key`**. Estas credenciais são necessárias para você executar alguns comandos, como por exemplo, em Pipeline via linha de comando na [**STK CLI**](home/stk-cli/index.mdx).

Esse tipo de autenticação possibilita manter uma sessão ativa com um tempo de expiração configurável para usar o STK CLI via linha de comando, como por exemplo, em pipelines de CI/CD.

Para fazer **as duas configurações**, siga os passos:

## **Como gerar o Token de Acesso Pessoal (PAT)**

**Passo 1.** Acesse diretamente link do [**Portal da Conta**](http://myaccount.stackspot.com); ou após fazer [**login no Portal StackSpot**](https://app.stackspot.com/), clique no **seu avatar de perfil**;
 
**Passo 2.** Selecione a opção **'Meu perfil'**;

**Passo 3.** No Portal da Conta, clique em **'Token de Acesso'**;  

**Passo 4.** **Agora você deve gerar as chaves do Token de Acesso Pessoal (PAT)** para serem informadas na linha de comando junto ao comando **`stk login`** na sua pipeline.

Clique no botão **'Gerar Tokens'**. Um tela será exibida informando os dados:

- **`Client ID`** ;
- **`Client Key`** ;
- Realm; e
- Exemplo de como usar.

Esses dados aparecem apenas uma vez. **Copie e salve as informações em um local seguro**.

Agora você pode utilizar as informações para se [**autenticar através do terminal**](#autenticar-via-linha-de-comando).

:::warning Atenção!  

- As chaves são geradas **por cada pessoa usuária da organização**, ou seja, se você gerar uma nova chave, a anterior se tornará inválida automaticamente. 

- Gerar uma nova chave não invalida as chaves de outras pessoas usuárias dessa organização. 

- Atualmente, o tempo de expiração da sessão é de **20 minutos**.

:::

## **Autenticar via linha de comando**

No terminal ou pipeline, preencha o comando substituindo os valores entre chaves pelos valores obtidos nos passos anteriores:

```bash
stk login --client-id <ID> --client-key <KEY> --realm <REALM>
```

Execute o comando acima sem as chaves **< >**.

:::tip Dica!  

É necessário fazer esta autenticação toda vez que você quiser automatizar algum processo na StackSpot. 

:::
