A integração do seu <Tooltip text="Source code management (SCM) rastreia alterações em um repositório de código, mantendo um registro de modificações e auxiliando na gestão de conflitos que surgem ao integrar atualizações de diferentes colaboradores.">SCM</Tooltip> (Source Code Management) com a StackSpot traz utilitários para as equipes e podem ser executados remotamente via pipeline de CI/CD.

 Atualmente, a StackSpot disponibiliza 5 fluxos para execução: 

1. Criação de Aplicação;
2. Criação de Infraestrutura;
3. Aplicação de Plugins;
4. Execução de Actions;
5. Execução de StackSpot Workflows.

A configuração do SCM com Workflow da StackSpot suporta os SCMs a seguir:

- GitHub;
- Azure DevOps;
- BitBucket;
- GitLab.
