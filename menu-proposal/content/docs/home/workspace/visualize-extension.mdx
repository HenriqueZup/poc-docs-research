> Nesta seção, você encontra os passos para visualizar uma Extensão Customizável. 

## **Introdução**

No contexto da StackSpot, uma Extensão Customizável permite criar uma nova página dentro do Portal da StackSpot EDP. Para isso, a plataforma oferece um SDK que possibilita o desenvolvimento de páginas personalizadas, totalmente integradas ao ambiente da StackSpot EDP.

A Extensão facilita a integração com outras ferramentas, oferecendo uma experiência centralizada e personalizada para as pessoas desenvolvedoras.

Uma Extensão também pode usar informações da StackSpot por meio de uma [**biblioteca específica disponível no npm para facilitar a troca de informações**](https://www.npmjs.com/package/@stack-spot/portal-extension).

- **Permissão necessária**: visualização de Extensão. 

### **Passo a passo** 

**Passo 1.** Acesse o [**Portal da StackSpot EDP**](https://app.stackspot.com/) e, em seguida, clique em **’Workspaces’**;

**Passo 2.** Em seguida, clique em **’Extensões’**;

:::warning Atenção!

Este menu só será exibido se houver pelo menos uma Extensão cadastrada e ativa pra Workspace na Organização que você faz parte. 

:::

Pronto, agora você pode visualizar e usar a Extensão cadastrada no Workspace.
